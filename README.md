#  IceBreaker 2000 🎰

IceBreaker 2000 is a slot-machine-style question generator for starting conversations.
Spin once, get a prompt, and use it as an icebreaker!

Try it here! [IceBreaker 2000](https://icebreaker-2000.pages.dev/)  

Tip: *install it to your mobile device for offline inspo on the go!*  
- In your mobile browser, navigate to the website  
- Tap the menu icon (three dots in the top-right corner)  
- Select "Install app" or "Add to Home screen"  

## How It Works

- `SAFE` mode: spins and lands on a complete question for a straightforward conversation starter.
- `CHAOS` mode: spins 3 reels (Opener, Descriptor, Topic) and combines them into one wild, random prompt. May or may not make sense but will make everyone laugh!
- Theme controls
  - Cycle through 3 color themes
  - Toggle light/dark mode

## Quick Start

```bash
pnpm install
pnpm dev
```

Then open the local URL shown in your terminal (usually `http://localhost:5173`).

Optional:

```bash
pnpm build
pnpm preview
```
